## 根据所引用聊天补齐的内容

已只读“修复去除 LZ77 工程时序违例”，并核对其报告需求和用户提供的
`server_TD_report/20261023report.tar.gz`。该归档包含约44–46MB的详细时序、
约15MB的完整GUI时钟树，以及时钟交互、Path Skew、Noise、高扇出和逻辑级数报告。
旧服务已经支持这些文本/CSV后缀；主要缺口是没有自动生成相应报告，手动导出目录也不在任务回传范围内。

新构建在所选原生run的 `controller-reports/` 下生成：

| 报告 | 文件与内容 |
|---|---|
| 详细Timing | `timing_detail.rpt`，Max/Min、100端点/路径组、每端点3条路径，包含ignored路径，保留头部和正常路径 |
| Clock Intersection | `clock_intersection.txt`，原生时钟交互报告 |
| Clock Tree | `clock_tree.txt`，原生XML时钟摘要；完整拓扑限制见下文 |
| Path Skew | `path_skew.rpt`，Max/Min、100端点、每端点3条，不省略详细路径 |
| Noise | `noise.csv`，含phase；仅物理布线后执行，不等同板级电气验证 |
| Device Setting | `device_settings.txt`，原生 `report_cfgs` 的器件设置/配置表；`device_settings.json` 保留实际AL硬件、设置、配置和Run属性来源 |
| 高扇出 | `high_fanout.txt`，当前gate/place/route阶段的前100条及timing数据 |
| 逻辑级数 | `logic_level.rpt`，最差100项 |
| 时序例外 | `timing_exception.rpt`，扩大到100×3 |
| Run参数 | `run_parameters.txt`，TD原生run参数文本 |

RTL、Gate、Physical资源报告，以及流程自带 `*_chk.timing` 的Check Timing仍原样回传。
不在重开DB后额外重复执行Check Timing：本机TD2026.2该额外调用曾出现C++崩溃，
正常原生route流程已经生成详细检查报告，直接保留它更可靠。
本版使用实测接受的 `max_min` 参数拼写；手册部分位置写作 `min_max`，当前程序会拒绝后者。

新增 `reports.json` 清单及 `result.reports` 摘要，记录源提交、project、seed、run、文件路径、
大小/哈希/时间、生成状态和继承来源。生成、空文件、缺失、命令失败、不可用、不适用、旧文件及摘要范围分别标明。
`GENERATED`仅表示生成了报告文件，不表示时序或检查通过；100×3仍是扩大抽样，并非穷举全部路径。
空Path Skew或Noise数据不作为通过结论。

## 完整Clock Tree的工具限制

本机6.2.3.210850批处理 `report_clock_summary` 可稳定生成XML时钟组摘要，
但实测未导出GUI文件中的逐pin拓扑。已核对官方命令并测试时钟列表、命名、append、
重新绑定SDC及计时前/后的调用；这些调用没有补出GUI拓扑，因此没有把摘要冒充完整报告。
清单自动检查XML：含pin拓扑时标记 `FULL_TOPOLOGY`，只有摘要则标记 `SUMMARY_ONLY`，
整体报告状态为 `PARTIAL`，同时编译阶段仍可正常DONE。
服务器Linux版本若输出完整拓扑会自动识别；本次没有服务器侧完整拓扑实测资格。
需要与手动GUI导出完全相同的时钟树时，仍应在对应job原生run打开后导出。
可另存为该job的run目录中的 `manual-clock-tree.txt`，现有文件收集会随下一轮回传；
不要覆盖自动报告或改写其清单，补充文件与自动生成范围分别保留。

## 回传与兼容

全部文件位于任务自己的AL/Runs或job根目录；沿用现有每分钟轮询、8MiB分块、32MiB/轮预算和SHA256校验。
新增清单也被收集，大报告可跨多轮续传。DB继续保留服务器，不上传；bit仍只在bitgen完成后发布。
同名旧诊断只在新接续任务的副本中清除后重生成；父任务、已完成qualification、手动GUI和原始输入不覆盖。
旧任务不因程序更新而自动重编或自动补报，已经取回的人工报告不重新归类为新源码结果。
v6 `capabilities.reports_profile` 为 `timing-diagnostics-v1`。

## FinalShell更新

将 `td-simple-update-20261023-v6.tar.gz` 上传到 `/home/build-user/td_simple/bootstrap/`，以build-user执行：

```bash
tar -xzf /home/build-user/td_simple/bootstrap/td-simple-update-20261023-v6.tar.gz -C /home/build-user/td_simple/bootstrap
bash /home/build-user/td_simple/bootstrap/server/td/simple/apply_update.sh
```

包内无凭据，tar条目使用正常mtime。安装器等受控任务自然结束再替换，保留队列、认证、资源历史和已有成果；不重新执行旧任务停止工具。
完成后应看到 `Controller: 2026.10.23-reports-v6`，并通过新鲜共享status核对版本和reports_profile。
安装成功不意味着已经服务器实测新报告，也不意味着Clock Tree完整拓扑限制已消失。
