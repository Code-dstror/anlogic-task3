# Additional public contracts: cancellation and diagnostic sink

These are independent public IO contracts. Production implementation files stay opaque. Do not read old benches/runners or internal hierarchy. A maintainer-generated declaration-only file `extra_public_ports.txt` accompanies this document.

## Dehaze cancellation boundary

Target `dehaze_dcp_restore4`, legal small profile WIDTH=256, HEIGHT=128, EXTERNAL_DARK_ENABLE=0; one 125 MHz clock, no vendor dependency. Opaque source `refactor/camera_raw_r1/src_fpga/rtl/dehaze_dcp_restore4.v`. Four pixels per beat, RGB bytes each [23:16] R, [15:8] G, [7:0] B, lane0 low24; four luma bytes corresponding low8. SOF first accepted group, EOL every 64 accepted groups. RAW pixel cannot advance without s_valid&&s_ready; m_valid&&m_ready is accepted output, elastic stalls preserve offered tuple except explicit clear/reset cancellation. Session/epoch/sequence/camera stable for each accepted frame; matching terminal may arrive before/at/after pixel tail and establishes success only if entire geometry good. i_history_reset invalidates history, i_enable0 yields exact identity RGB/Y. i_enable1 with no valid history likewise yields identity. The airlight clamp is [192,248]. Uniform grey192 has R=G=B=A=192, reconstruction I−A=0 and Y=192, so repeated valid uniform192 frames remain 192 even when using history. The initial handoff's grey128 did not satisfy the clamp and was corrected before any DCP run. History publication requires positive matching terminal and complete build. Minimum geometry is 8192 beats, with at most a few frames; no 1080p simulation.

`clear` cancels pending pipeline work and incomplete frame; no old data is allowed after cancellation into a new frame. It preserves previously committed history in both eyes. `i_history_reset` or cold `rst_n` invalidates history. `o_history_used` is the current frame's held status after an accepted SOF, checked at its first valid output: committed history is usable for the same eye/session/epoch with a forward sequence delta of 1–4. Clear/reset drives the held status to zero. READY may remain closed for a bounded flush bubble; no fixed cycle latency is required. No completion is fabricated. Keep source off through cancellation then submit new SOF once ready. Appropriate tests: cold identity, clear with held head/body/last and a distinct recovery frame; matching terminal at/around clear; double clear; one committed uniform frame per eye to check history identity, and reset under stall followed by a legal first frame. The consumed cancelled prefix is legitimate. Flush the scoreboard at clear, count handshakes with clear low, and assert READY closed while clear high. Per-case wall ≤60 s and simulated watchdog ≤1 ms.

## Read-only field diagnostics and UART DJ/v2

`camera_field_diagnostics` has independent DFI/PIX clocks/reset; only outputs dfi_page/pixel_page. All input events are one-cycle pulses in named domain. If run=0 counters hold; on run0→1 reset counters including same-edge events (so simultaneous event counts1), then modulo increment every pulse. Last SOURCE per eye records actual job_fire sequence, is zero on new RUN before first job. Mode/epoch changes do not reset counts; use stable windows by epoch, not mixed windows. Negative events preserve actual eye. bad_finish already is per-eye OR of L/S failures in a cycle; count cycle not individual simultaneous L+S. All counters are observational only.

DFI page little-endian bit offsets: 0seq0/32b,32seq1/32b,64epoch/32b,96session/32b,128jobs0/16b,144jobs1/16b,160reject0/8b,168reject1/8b,176expire0/8b,184expire1/8b,192bad0/8b,200bad1/8b,208bank_states/8b,216dfi_flags/8b. Bank2bit codes0FREE1BUILD2READY3OWNED, cam0bank0,cam0bank1,cam1bank0,cam1bank1. Flags0RAW,1HDR,2RUN,3ticket_recovery,4processing_fault,5bridge_fault,6read_quiet,7HDRowner_empty.

PIX page:0fs0/16b,16fs1/16b,32admit0/16b,48admit1/16b,64admit2/16b,80admit3/16b,96..159zero reserved,160flags/16b,176epoch/32b,208..223zero. HDR admissions are CAM0 LONG, CAM0 SHORT, CAM1 LONG, CAM1 SHORT. SDR admissions firsttwo are CAM0/CAM1, others0. Flags bit0HDRreq,1stereo,2RAW,3cfg_pause,4cam0_mode_running,5cam1_mode_running,6cam0_HDRstable,7cam1_HDRstable,8cam0_config_done,9cam1_config_done,10cam0_config_error,11cam1_config_error,12cam0_identityfault,13cam1_identityfault,14cam0_receivefault,15cam1_receivefault.

Composite UART target `uart_status_observer` parameters UART_DIV=2,REPORT_INTERVAL_CYCLES=5000,SNAPSHOT_TIMEOUT_CYCLES=256,CFG_DIAG_ENABLE=1,CFG_FRAME_VERSION=2,JOB_PAGE_ENABLE=1,JOB_SYS_CONFIG_ENABLE=1,RX_DIAG_ENABLE=0,RX_TRACE_ENABLE=0. Opaque dependency list: `uart_status_observer.v`, `uart_observer_snapshot.v`, `cfg_diag_snapshot.v` from same RTL root (and `camera_field_diagnostics.v`). Connect `i_cfg_domains={pixel_page,dfi_page}` and its reset bits 0=DFI, 1=PIX. SYS input i_job_sys_config[63:0] is coherent in SYS; low32cam0/high32cam1 config diagnostics. The UART freezes these at packet FREEZE and overlays PIX bits96..159 without sampling them through PIX CDC. Sensor32 fields index[23:16],phase[15:12],lock[11],abort[10],sourcefault[9],pair_event[8],pair_ok[7],written[6],stable[5],error[4],write_valid[3],write_ready[2],done[1],NACK[0],warmup[31:24]. SYS snapshot time is independent of DFI/PIX snapshot times.

Wire 115200-equivalent8N1 serialized with configured divisor, no RX. Existing OB29B emitted then DJ68B. DJ bytes0..5=44 4a 02 01 44 00;6..7sequence little endian;8freshmask bit0DFI bit1PIX;9resetmask same;10..37DFI224b;38..65PIX224b;66..67 CRC16/CCITT-FALSE overbytes0..65, initialffff/poly1021/no reflection/xorout0, lowbytefirst. Frozen packet must not tear if inputs change during transmission. A stopped or reset domain can mark fresh/reset false; its payload must not be treated current. No user command/ack pin.

Minimal tests: helper counters with mixed-eye first-RUN pulses, stop/resume, epoch change and 8-bit wrap; UART actual wire header, CRC and field mapping with real helper and snapshot leaves; SYS/DFI/PIX inputs changed during transmission; finite stop of PIX clock while SYS/DFI continue, yielding a bounded stale mask and later recovery.

The opaque Python decoder (`refactor/camera_raw_r1/tools/uart_observer.py`) is loaded only as the DUT. `FrameDecoder(pixel_layout='stereo').feed(bytes)` returns valid event dictionaries; `decode_job_frame(bytes)` parses one complete frame. A job event carries `frame_type='job'` and `version=1/2`. DJ v1 uses the same 68-byte header/CRC shape with byte2=1 and a legacy schema (PIX bit96 first admission, 97..99 state, 100..103 ticket, 104 stalled, 105..159 zero). V2 events expose DFI last_source/epoch/session/jobs/begin_reject/pair_expire/bad_finish/raw/hdr/run, PIX fs/capture_admit/epoch/hdr/stereo/raw, and `sensor_sys` with two sensor dictionaries. Feed independently formed DJ v1/v2 in one-byte fragments with noise, truncated data, an invalid header, a corrupted CRC and a good frame. Assert recovered frames and public `crc_errors`, `invalid_headers`, `discarded_bytes` and `summary()` job error counters.
