# 相比上一版41cb5991 / seed56的改进

本包：camera_raw_r2，源1a5603c1，seed25；直接对照上一轮实际调试的41cb5991 / seed56。
上一版的HDR30/20已由540秒现场记录确认：四路曝光准入均约30.306/s，但CAM0/CAM1实际job为30.306/20.204/s，后级计数跟随job。慢眼随重入交换，也曾出现25/25。

| 本轮改动 | 改进与验证范围 |
|---|---|
| HDR T96从一像素/拍改为两像素/拍 | 共享组缓存和控制，保留96段曲线、ROM、定点精度、舍入与饱和。125MHz下纯计算下界从16.5888ms/1080P帧降到8.2944ms。独立黑盒16384像素逐位一致，HDR每组4→2拍，SDR仍每拍一组。 |
| HDR reader增加16字响应预取 | 重叠下一burst首响应等待与旧RAW10解包，保留一笔真实AXI outstanding、16beat、4KiB和槽归还证明。真实仲裁读链短模型3515→2421拍，像素、身份和事务数一致；取消、反压、错误响应及恢复通过。 |
| SOURCE/JPEG局部复位时序 | 已持事务的数据资格改用原上升沿同步级，异步复位仍由下降沿释放；首个合法握手边界不变。实际跨域FIFO/cleanup黑盒新旧公开事件一致。没有放宽时钟或增加宽泛false path。 |
| RK现有参数目录 | caps/discover补齐原JPEG质量、预算、自适应、restart与HDR运动/计时字段和边界文档。6组SDK、5组真实CFG/CDC短测通过。未开放黑电平或新硬件参数。 |

真实owner的短服务模型复现了30/20、25/25及慢眼交换，并在缩短服务时间后各眼完整接纳。它证明有限bank与服务时限的机制，不能代替本bit满幅持续30/30板测。

原CFG1/schema2、AJPG v4、ARAW v1、UART OB/v2与DJ/v3格式保持。单目SDR60、双目SDR30、单双目HDR30目标、灰度/高斯/HE、单目原车道、双目去雾和RAW冷选均保留。Q75、传感器曝光配方、HDR黑电平50/50、ratio4（16×）未改变。RAW仍是经过DDR槽的未压缩RAW10，不是无损压缩或DDR旁路。

已继承旧版quiet排空、whole ACK后APPLIED发布、孤立SHORT启动与160字HDR chunk修复。既有RK私有BOOT兼容、同owner、分眼收包/MPP逻辑继续使用，不能用本包通用SDK覆盖掉现场必要适配。

本包物理时序和实际整机资源见TIMING_REVIEW.md；短测/小综合与新板级性能分别判定。本bit所有板级项从NOT_RUN开始。
