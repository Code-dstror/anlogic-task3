# TD Release 2026.2：版本选择与兼容边界

本项目目标仍为 **PH1A90SEG324-2**。**Codex 新任务默认使用新版**，安装在
`C:/Tools/Anlogic/TD_2026.2`，实测日志版本为 **6.2.3.210850**，Tcl 为
8.6.17。FDI6 已发布运行及板测属于旧安装
`C:/Tools/Anlogic/TD_6.2.168116`（6.2.168116）。
本轮仅作兼容检查，主工程完整布局布线、最终 STA 和新版主工程 bitgen 为
NOT_RUN；结果见 [兼容记录](../../../../docs/evidence/td2026-compat-20261005/README.md)。

## 选择工具和输入

1. 批处理使用 `python tools/run_td.py <script> --td-root C:/Tools/Anlogic/TD_2026.2 --workdir <project-dir> --log <log>`。
   每次显式传新版根目录，优先于环境和发现结果；旧 PATH/根变量可能仍指旧安装，不能省略参数或静默回退。
   仅明确要求历史复现、版本对比或核对 IP 来源时选择旧版。相对 IP/include 路径需要正确的工程工作目录。
2. 启动器在子进程中统一 `TD_HOME`、`TD_ROOT`、`ANLOGIC_TD_ROOT`、`TD_INSTALL_DIR`，
   并将对应 `bin` 放在 PATH 首位。实测新版程序配旧 `TD_ROOT` 会在 `import_device`
   触发设备库断言；统一根目录后通过。不要为单次测试修改 Windows 系统/用户变量。
3. 原生 GUI 使用 `C:/Tools/Anlogic/TD_2026.2\bin\td.exe`，启动也应使用一致的进程根变量。TD Tcl 的
   `open_project`/`open_run` 不证明正在显示的 GUI 窗口已经刷新。补做的 GUI 启动检查仅核实
   进程响应和主工程标题，内部任务面板未作目视核验；结果见同一份兼容记录。
4. 对比工具版本时使用隔离副本、单独的 `.al`/Runs 和仿真编译库，核对原输入字节。
   当前源和受保护 IP 使用既有配置；加载 `.ipc/.xml` 不等于使用新版重新生成 IP。
5. 新安装的 `arch` 是器件库，`sim_release/ph1` 是 PH1A 模型，`ip` 是生成器和 depot。
   其中仍有 `ip/depot/Soft_FIFO_3.0`、`UART_1.0`，也有 `ip/soft_fifo` 等辅助目录。
   不按目录名推断生成器文件相同；官方源比较应使用 provenance 记录的原始工具版本。

## 从原文确认的变更

下列页码均为物理 PDF 页。依据是本地官方原文，未从其他器件的更新推断 PH1A90 参数。

| 项目 | 本项目使用时的含义 | 依据 |
|---|---|---|
| PLL 参考时钟 | 未约束参考时钟时不再从 PLL 输出自动 derive；检查 USR-8226 和 Check Timing，再补正确约束 | [Release Notes](../../../../references/vendor/安路科技_TD_技术文档/2026.2/release_note.pdf)，p.6 |
| LCLK 分频 | 输出未约束时新增 USR-6125 提示；不能凭旧版成功推断时钟已覆盖 | Release Notes p.6 |
| Placement 参数 | `logic_level_opt` 默认从 off 变为 auto，可选 auto/on/off；对比时明确记录实际参数 | Release Notes p.7 |
| Routing 参数 | Routing 界面移除 timing；旧工程非默认值会提示无效。旧 `route timing` 表不能直接作为新版依据 | Release Notes p.7 |
| 综合策略 | PH1/PH2 移除 RAMOptimize；旧工程会提示 PRJ-6602/6612 并切换到 Default_Synthesis_Strategy | Release Notes p.8 |
| CDC/MTBF | PH1 可调用 `check_cdc` 和 `report_mtbf`；命令存在和生成报告不代表 CDC 签核 | Release Notes p.9；[SWUG117](../../../../references/vendor/安路科技_TD_技术文档/2026.2/SWUG/SWUG117_Analysis_Tools_User_Guide.pdf)，pp.25–26 |
| IP 版本锁定 | 旧 IP 可能可用于 Flow、但锁定重新生成；Upgrade Selected/Generate 会修改 IP。兼容测试保留现有生成物 | [SWUG118](../../../../references/vendor/安路科技_TD_技术文档/2026.2/SWUG/SWUG118_IP_Catalog_Tools_User_Guide.pdf)，pp.14–18 |

`check_cdc` 在 placement/routing 后或加载相应检查点时使用，只分析有相关时钟约束的路径。
单时钟小测试的空 CDC 报告不能证明主工程跨域安全。新增命令并不取消本项目的握手、复位、
SDC 对象绑定和最终 Both corner 检查要求。

## 文档版本和仿真库

- 新版原件放在 `references/vendor/安路科技_TD_技术文档/2026.2/`，旧版原件保留。
  用户下载的两份 PDF 与安装内用户手册/release note 的 SHA256 相同。
- TD 用户手册封面仍是 **V6.2 / 2026.08**；多数新版 SWUG 是 TD2026.2，
  SWUG107/SWUG113 则是 TD6.2.2 / 2026.01。安装版本与手册内部版本分开记录。
- IPUG035 新副本是 **v1.5 / 2026.07**；旧版生成的 DDR IP 不因此自动升级。
  UG910 v1.6、IPUG011 v1.4、IPUG013 v1.0、SWUG110 v1.1 与既有副本相同，目录补记来源。
- 本轮核对 14 个所用模型，5 个哈希改变：ERAM/FIFO 的 `ph1_logic_eram.v`、
  `ph1_logic_fifo.v`、`ph1_phy_eram.v`，以及物理模型 `ph1_phy_lslice.v`、
  `ph1_phy_pad.v`。重编必要模型，仿真输出按版本隔离。
  ModelSim SE-64 2020.4 的 SDF 测试保留了负 timing limit 被归零的警告；不将其用于完整物理签核。
- 涉及 TD 模型的仿真 runner 显式传 `-TdRoot C:/Tools/Anlogic/TD_2026.2`
  或对应的 `--td-root`，避免沿用旧版环境默认值；纯自有 RTL 仿真按 runner 的实际参数执行。

本目录其他命令表、参数表、原语清单和仿真实验主要是 **6.2.168116 的历史测量**。
数量、默认值、选项和器件表只在对应版本内有效。查询新版时优先看以上原文及选定安装的
`info commands`、`get_param`/`report_param`；不要把旧表写成当前软件事实。
