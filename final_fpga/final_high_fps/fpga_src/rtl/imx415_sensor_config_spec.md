# Shared per-camera configuration

Each physical eye has one configuration sequencer and one I2C writer, running
on the existing always-running SYS25 clock. The SDR timing profiles and
DOL2 HDR use one ordered recipe interface. Each eye has its own physical bus.

The existing SDR 203-write order and HDR 139-write order are retained. SDR
gain and the three-bit SDR profile are sampled at START. The HD SDR rate
profiles override HMAX and SHR0 for the same 1080p/RAW10 geometry, MCLK and
lane rate. The UHD SDR profiles select all-pixel mode at the same MCLK and
lane rate.
The original HDR ROM supplies the DOL2 recipe. The accepted settings are held
for the entire I2C sequence.

SDR reset/release waits retain their original duration after conversion from
24 MHz to 25 MHz, rounded upwards. The STANDBY-cancel to XMSTA wait remains
25 ms for SDR and 24 ms for HDR. I2C uses one divider for both modes, no faster
than either previous mode. Successful ACK of the final register publishes
config_written; HDR still requires eight consecutive qualified pairs before
stable. Bad pairs restart that qualification. A PHY interruption before the
first qualified pair can recover through training. A receive fault after a
qualified pair, permanent identity loss or lost pair feedback invalidates HDR
configuration. A NACK or configuration clock lock loss invalidates the recipe.
After the digital COMMIT acknowledgment, a terminal error from an eye running
the required sensor profile completes CFG with RESET error and preserves the
previous public ACTIVE tuple. A successful CFG still needs the actual frame.

The caller reuses the existing quiet-qualified mode hold and sensor MCLK mux.
Changing SDR rate while SDR is active re-enters the same reset/configuration
sequence. A pending request must not retract an outstanding stream token or
become part of the drain condition. Actual mode_running remains separate from
requested-profile matching. CSI frame identity restarts only with the same
existing receiver cohort reset; no fabricated sequence or successful frame
is generated by a configuration ACK.

Legacy D2 selects sensor30 with capture divisor 1. Legacy D1 and D3–D255
select sensor60 with the requested capture divisor. The cold BAR extension
can select 40, 45 or 48 fps with capture divisor 1. HDR uses its DOL2 recipe
for every SDR selection and retains the choice for the next SDR transition.
Both eyes must report the requested SDR tag and completed configuration for
dual capture. The [HD rate contract](../../../camera_rate_r1/docs/RATE_CONTROL_CONTRACT.md)
defines the BAR registers and nominal timing values.

New local simulation, native resource and physical qualification are recorded
separately in the accompanying experiment. Electrical startup, actual frame
period and exposure still require the new source's bitstream and board.

## UHD SDR timing

With `MODE_4K=0` and `UHD_ENABLE=1`, profile 5 selects the established UHD15
recipe and profile 6 selects UHD20. Each uses sensor master mode, 24 MHz INCK,
720 Mb/s per lane, four lanes and RAW10. The timing clock is nominally 72 MHz.
HMAX is 1600 for both. UHD15 uses VMAX 3000 and SHR0 2254. UHD20 uses VMAX
2250 and SHR0 1504. The 22.222 µs line period and 746 integration lines give
approximately 16.580 ms including the 1.79 µs RAW10 integration offset. At
the nominal clock, the frame periods are 66.667 ms and 50.000 ms. The 20 fps
recipe removes 750 lines of frame blanking while keeping the line timing.

Sony IMX415-AAQR-G Datasheet revision E19505D2X (2022-10-17), SHA-256
`e6d82887370c34754208acc91333d333171eccbb57677bb5eb5d1c85a28ca838`, gives
minimum periods of 1017 clocks per line and 2238 lines per frame for the
all-pixel 4-lane RAW10 720 Mb/s case at INCK 24/72 MHz (physical p. 48).
The frame-rate rule on p. 53 allows independently longer line and frame
periods. The 720 Mb/s RAW10 example on p. 55 uses VMAX 2250 and HMAX 1066
with SYS_MODE 9. The pp. 70–73 shutter settings give the applicable SHR0
range of 8 through VMAX minus 4. The nominal 24 MHz and lane settings are
already used by the candidate. Confirm actual XVS/CSI FS and FE cadence,
line packets, optical crop and Bayer phase with the target module.
