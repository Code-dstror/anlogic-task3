# RTL 局部规则

生产 RTL 默认可综合 Verilog-2001，模块/文件同名，时钟、复位、位宽和数值范围明确。
定向测试台可使用 ModelSim 支持的 SystemVerilog。实现维护者先读目标 spec、直接
上下游和实际生产参数；不通配混入同名历史模块。TD/模型版本按根 `ENVIRONMENT.local.md`
选择，显式传 `--td-root`/`-TdRoot`，不重生成已有 IP。

## 独立黑盒功能验证

- 测试作者使用新建且不继承实现上下文的子代理。只交付公开 IO 声明、合法参数
  组合、数学/线协议合同、必要的外部故障现象与不透明编译清单；不得给出实现代码、
  旧测试逻辑、内部状态推导或把现有 DUT 输出当 oracle。参数名不能代替合法 profile。
- 测试代理禁止读取生产 RTL、厂商模型实现、旧 TB 或内部层次信号；可编译这些文件、
  取 SHA、观察公开端口，并在公开接口注入反压、错误响应、复位或停钟。缺依赖、编译
  源行和实现定位由主代理处理，只向测试作者返回接口/依赖信息。工具不支持独立代理
  时如实说明限制，不能把主代理自测称为独立黑盒。
- 合同先定义脉冲与保持电平、采样沿、READY 前置、借用数据寿命、同拍优先级、取消与
  复位、序号环绕和未定义输入。BEGIN 结果、SAFE 接收、DONE、drained、最终退休分别
  判定；不能靠名字猜事件或把 FIFO 条目计数当 RAW4/帧计数。
- 从已出现的问题选择最小充分短门：合法首事务到真实终态、连续事务、有限反压、
  尾拍/边界、取消后的承诺排空、坏输入和下一事务恢复。每次运行前设墙钟与仿真
  watchdog；默认小几何和短控制序列，不因“全面检查”自动启动数小时满幅多帧测试。
- 失败先区分 DUT 缺陷、接口合同缺口、测试台错误和工具/依赖失败。不得迎合 DUT 改
  正确期望；合同未定义处单列观察并由维护者给出规范依据。保留原 FAIL 和日志，
  修复后另开运行目录。满足该风险的门槛后停止，新增变更/失败/覆盖缺口才补测。
- 记录具体场景、准确命令、输入与 TB 哈希、工具/模型版本、终态和未覆盖边界。数值
  oracle 来源应独立于 RTL；模型/算法验证、功能仿真、综合、P&R、板级分别报告。
  详细模板见 `.agents/skills/rtl-stream-contract/references/blackbox-validation.md`。

## 流、身份与所有权

- 只在真实 `VALID && READY` 时推进；stall 保持有效数据及 sideband。相机 EOL、
  真正 FE、SOURCE、JPEG/RAW record LAST、DMA 完成属于不同边界。
- 相机不能无限反压。坏 CRC、几何/身份错误、溢出或复位中止不得提交成功帧；冻结
  camera/session/epoch/sequence/generation/lease，不能重复旧图、重新编号或放宽检查凑帧率。
- 多位 CDC 用受审 FIFO/握手，单 bit 用同步器；扩展 mailbox/快照字段同时补对应
  约束。复位异步断言、本域同步释放与停钟恢复须有结构和验证依据，不用状态组合
  译码直接制造运行期异步复位，也不用宽泛 false path 掩盖问题。
- 帧槽 READY 需真实写响应和匹配 SOURCE 成功。末拍/已承诺 AXI burst 未排空不能释放槽。
  正常退休区分目标槽与无关槽；STOP、配置切换和故障仍需规定的全局排空。
- 涉及帧率或吞吐时，同时核查物理 FS cadence、捕获准入、job、处理结果和退休；双眼错相或背压不能
  造成额外分频。小图控制吞吐不能代替真实满幅性能，首帧延迟也不等于稳态 FPS。
- 优化以当前瓶颈和同源同设置 A/B 为依据。功能、精度和外部 ABI 保持；LUT/FF/ERAM/
  DSP 的外围逻辑及路由代价都计入，不为极小概率异常堆新状态、帧缓存或大历史探针。

## 范围

`src_fpga/ip/vendor/` 和已冻结 IP 保持原字节；仿真替身只供专用 runner，不进入 TD。
UART 默认旁路只读，有限状态/计数不反馈业务 READY、复位或准入。原线上常量由协议
JSON/生成器维护；新增功能显式扩展，不能静默改变已有 RK 报文格式。
普通修复不触发 `readable-verilog-generator` 的全套生成/风格门禁；该包仅用于请求其
完整生成或结构审查的工作。原生展开、约束对象匹配及小综合属于实现检查，不冒充黑盒仿真。
